# Logos

- `eternatus-logo.png` — o logo completo (frasco, cartas, dado, peão e o nome ETERNATUS Card House) com fundo transparente. É a versão de uso em todas as telas, sempre sobre `cream` ou `paper`.
- `eternatus-logo-original.png` — o arquivo enviado, com fundo branco. Guarde como fonte; não use sobre creme.

A marca tem várias cores (azul-marinho, bordô, branco) e não tem versão monocromática nem negativa: nunca a coloque sobre `navy-950`/`navy-800` nem a recolora. Altura mínima: 32px.
