Tabela base sem zebra: linhas separadas por `line`, cabeçalho em eyebrow `ink-muted`.

**Você fornece:** a estrutura com `TableHeader`, `TableBody`, `TableFooter`, `TableRow`, `TableHead`, `TableCell` e `TableCaption`.

- Para listas de dados com colunas definidas use `DataTable`, que já monta tudo a partir de `columns` e `rows`.
- Envolve a tabela num contêiner com rolagem horizontal: em telas estreitas a tabela rola em vez de quebrar.
- Números em `tabular-nums` e alinhados à direita.
