Liga/desliga de uma configuração que vale na hora (inscrições pelo link, late reg, standings público).

**Você fornece:** `checked`+`onCheckedChange` (ou `defaultChecked`), `label` e opcionalmente `description`, `disabled`.

- Trilho `neutral-soft` com borda `control-border`; ligado, `navy-800`. Polegar `card`.
- Com `label`, vira uma linha de 44px com o texto ao lado; o label inteiro é clicável.
- Sem `label`, passe `aria-label`; a área de toque continua 44px de altura.
- Use `Checkbox` quando a escolha só vale depois de "Salvar" ou faz parte de uma lista.
