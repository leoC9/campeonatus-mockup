Botão liga/desliga para um filtro isolado; ligado fica em `info-soft` com texto `info-ink` (Radix Toggle).

**Você fornece:** `children`, `pressed`+`onPressedChange` ou `defaultPressed`, e `variant` (`default` sem borda, `outline` com borda `control-border`).

- Para escolher uma entre várias opções use `Segmented`.
- Texto sempre visível; ícone sozinho só com `aria-label`.
