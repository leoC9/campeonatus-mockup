Barra de progresso fina: trilho `neutral-soft`, preenchimento `navy-600` (Radix Progress).

**Você fornece:** `value` e `max` (padrão 100) e um nome acessível (`aria-label`).

- O número vem por escrito ao lado ou acima; a barra nunca é a única informação.
- No backoffice, use dentro do `ProgressCard`.
