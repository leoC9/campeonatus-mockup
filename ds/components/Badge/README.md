Etiqueta de status curta, sempre com palavra e em par fundo/texto.

**Você fornece:** `children` (uma ou duas palavras) e `tone`.

- `info` — Abertas, Inscrições abertas, Finalizado, Rodada 3 de 4, Link, Ativo.
- `danger` — Últimas vagas, Falta reportar, Tempo esgotado, pendências.
- `neutral` — Em breve, Balcão, Desativado, Drop (jogador dropado), chips de formato (Standard, Suíço 4 · Bo3).
- `warn` (`gold-soft`/`gold-deep`) — Late reg. É o único uso de atenção; não crie outro tom dourado.
- `outline` — Inscrições (estado ainda não iniciado na lista do backoffice).

Nunca use a cor sozinha para dizer o estado; o texto é obrigatório.
