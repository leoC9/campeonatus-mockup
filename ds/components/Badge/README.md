Etiqueta de status curta, sempre com palavra e em par fundo/texto.

**Você fornece:** `children` (uma ou duas palavras) e `tone`.

- `info` — Abertas, Inscrições abertas, Finalizado, Rodada 3 de 4, Link.
- `danger` — Últimas vagas, Falta reportar, pendências.
- `neutral` — Em breve, Balcão, chips de formato (Standard, Suíço 4 · Bo3).
- `warn` — Late reg.
- `outline` — Inscrições (estado ainda não iniciado na lista do backoffice).

Nunca use a cor sozinha para dizer o estado; o texto é obrigatório.
