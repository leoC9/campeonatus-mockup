Grupo de botões encostados: borda `control-border`, divisórias `line`, selecionado em `info-soft` (Radix ToggleGroup).

**Você fornece:** `type` (`single` ou `multiple`), `value`+`onValueChange` ou `defaultValue`, um `aria-label` e os itens `ToggleGroupItem` com `value`.

- É a base do `Segmented`; prefira o `Segmented` quando o grupo nunca pode ficar vazio.
- Use direto para seleção múltipla (`type="multiple"`).
